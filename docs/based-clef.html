Based Clef (bclef) Quickstart

Sub-second browser and Linux desktop automation driven by Cloudflare Clef decision models (@cf/cloudflare/clef-flash), Intent-to-Playbook compilation, Web Studio, and Human-in-the-Loop safety gates.

01 Install & Run Instant Sandbox Demo

git clone https://github.com/paschalla/based-clef.git
cd based-clef
python3 -m venv .venv && ./.venv/bin/pip install -e ".[all]"

# Verify readiness & run local demos (zero API keys required with --offline)
./.venv/bin/bclef doctor
./.venv/bin/bclef demo --portal --offline --headless
./.venv/bin/bclef studio --offline --open

02 Configure Cloudflare Workers AI (chmod 600)

# Interactive setup wizard (writes ~/.config/based-clef/env with 0600 permissions)
./.venv/bin/bclef init

03 Intent → Blueprint → Execution Modes

# A. Preview compiled Action Sequence Blueprint without clicking anything
./.venv/bin/bclef plan "Open wikipedia.org -> search 'Alan Turing' -> open article"

# B. Direct Drive with #ff33cc target outlines & RAM-only form credentials
./.venv/bin/bclef run "Log in with the given email and password" \
  --url "file://$PWD/decision_agent/demo/login.html" \
  -d email=operator@example.com -d password=hunter2 --highlight \
  --save-playbook login.playbook.json

# C. Blueprint Preview Gate (--preview) or Step-by-Step Co-Pilot (--step)
./.venv/bin/bclef run "Search wikipedia.org for 'Alan Turing' and open the article" --preview

# D. Launch Web Studio, Floating X11 HUD, MCP Server, or Unix Socket IPC
./.venv/bin/bclef studio --port 8765
./.venv/bin/bclef gui
./.venv/bin/bclef mcp
./.venv/bin/bclef ipc

04 3-Tier Decision Ladder & Probability Gates

Tier Model Role & Trigger Typical Latency
Ladder 0 @cf/cloudflare/clef-flash Single-pass calibrated probabilities over P1[target], P2[action], P3[done], P4[sensitive] (gate ≥ 0.70). ~200–350 ms
Ladder 1–2 @cf/meta/llama-3.3-70b-instruct-fp8-fast Compact ≤2-sentence stage-aware hint rewriter when Clef confidence < 0.70; re-queries Clef. ~750 ms
Ladder 3+ @cf/meta/llama-4-scout-17b-16e-instruct Multimodal escalation fallback if Clef remains uncertain after max_attempts=3. ~1.2 s

Zero-Leak Secret Isolation

Passwords mask as *** in DOM snapshots and never enter Clef/LLM prompts or exported Playbooks. Secrets live in RAM and persist to ~/.config/based-clef/secrets.env (0600) only upon task completion.

Sensitive & OAuth Gates

Irreversible clicks (P4[sensitive] ≥ 0.5 or payment/delete keywords) and OAuth flows pause execution and surface an interactive Approve/Deny banner in Studio, CLI, or HUD.

Clef Schema Guardrails

Guarantees ≥2 choice criteria even on blank/loading DOMs (preventing HTTP 422), caps screenshots at 1 JPEG frame (quality=60), and strips base64 from training.jsonl.
